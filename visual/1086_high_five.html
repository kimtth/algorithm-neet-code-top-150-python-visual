#1086 High Five

Given a list of student scores (id, score), return the top 5 average for each student sorted by id.

🔺 Heap 📊 Sorting ⏱️ O(n log n) 💾 O(n)
📄 Python: python/1086_high_five/1086_high_five.py

🧠 How It Works (Layman's Terms)

Group scores by student, keep top 5 for each:

  • Group: Use a dictionary to collect scores per student
  • Sort/Heap: Keep only top 5 scores for each student
  • Average: Calculate average of top 5 (integer division)
  • Result: Return [[id, average]] sorted by id

import heapq
from collections import defaultdict


"""
LeetCode High Five

Problem from LeetCode: https://leetcode.com/problems/high-five/

Given a list of the scores of different students, items, where items[i] = [IDi, scorei] represents one score from a student with IDi, 
calculate each student's top five average.

Return the answer as an array of pairs result, where result[j] = [IDj, topFiveAveragej] represents the student with IDj 
and their top five average. Sort the array by IDj in ascending order.

A student's top five average is calculated by taking the sum of their top five scores and dividing it by 5 using integer division.

Example 1:
Input: items = [[1,91],[1,92],[2,93],[2,97],[1,60],[2,77],[1,65],[1,87],[1,100],[2,100],[2,76]]
Output: [[1,87],[2,88]]
Explanation: 
The student with ID = 1 got scores 91, 92, 60, 65, 87, and 100. Their top five average is (100 + 92 + 91 + 87 + 65) / 5 = 87.
The student with ID = 2 got scores 93, 97, 77, 100, and 76. Their top five average is (100 + 97 + 93 + 77 + 76) / 5 = 88.6, 
which rounds down to 88.

Example 2:
Input: items = [[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100]]
Output: [[1,100],[7,100]]

Constraints:
- 1 <= items.length <= 1000
- items[i].length == 2
- 1 <= IDi <= 1000
- 0 <= scorei <= 100
- For each IDi, there will be at least five scores.
"""

class Solution:

    def high_five(self, items):
        scores = defaultdict(list)
        for student_id, score in items:
            if len(scores[student_id]) < 5:
                heapq.heappush(scores[student_id], score)
            else:
                heapq.heappushpop(scores[student_id], score)
        result = []
        for student_id in sorted(scores.keys()):
            avg_score = sum(scores[student_id]) // 5
            result.append([student_id, avg_score])
        return result


if __name__ == '__main__':
    # Example usage based on LeetCode sample
    solution = Solution()
    
    # Example 1
    items = [[1,91],[1,92],[2,93],[2,97],[1,60],[2,77],[1,65],[1,87],[1,100],[2,100],[2,76]]
    result = solution.high_five(items)
    print(f"Example 1: {result}")  # Expected: [[1,87],[2,88]]
    
    # Example 2
    items = [[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100],[1,100],[7,100]]
    result = solution.high_five(items)
    print(f"Example 2: {result}")  # Expected: [[1,100],[7,100]]
