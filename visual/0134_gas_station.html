#134 Gas Station

Travel around a circular route of gas stations. At each station, you get gas[i] and consume cost[i] to reach the next. Find the starting station to complete the circuit.

💰 Greedy ⏱️ O(n)
📄 Python: python/0134_gas_station/0134_gas_station.py

Example:

gas = [1, 2, 3, 4, 5], cost = [3, 4, 5, 1, 2]
Output: 3 (start at station 3)

🧠 How It Works (Layman's Terms)

Greedy algorithms make locally optimal choices:

  • Local best: At each step, pick the best option
  • No backtrack: Commit to choices
  • Prove: Local optimal leads to global optimal
  • Efficient: Usually O(n) time

💻 Python Solution

from typing import List, Optional

"""
LeetCode Gas Station

Problem from LeetCode: https://leetcode.com/problems/gas-station/

Description:
There are n gas stations along a circular route, where the amount of gas at the ith station is gas[i].
You have a car with an unlimited gas tank and it costs cost[i] of gas to travel from the ith station to its next (i + 1)th station.
You begin the journey with an empty tank at one of the gas stations.

Given two integer arrays gas and cost, return the starting gas station's index if you can travel around the circuit once in the clockwise direction, otherwise return -1.
If there exists a solution, it is guaranteed to be unique.

Example 1:
Input: gas = [1,2,3,4,5], cost = [3,4,5,1,2]
Output: 3
Explanation:
Start at station 3 (index 3) and fill up with 4 unit of gas. Your tank = 0 + 4 = 4
Travel to station 4. Your tank = 4 - 1 + 5 = 8
Travel to station 0. Your tank = 8 - 2 + 1 = 7
Travel to station 1. Your tank = 7 - 3 + 2 = 6
Travel to station 2. Your tank = 6 - 4 + 3 = 5
Travel to station 3. The cost is 5. Your gas is just enough to travel back to station 3.
Therefore, return 3 as the starting index.

Example 2:
Input: gas = [2,3,4], cost = [3,4,3]
Output: -1
Explanation:
You can't start at station 0 or 1, as there is not enough gas to travel to the next station.
Let's start at station 2 and fill up with 4 unit of gas. Your tank = 0 + 4 = 4
Travel to station 0. Your tank = 4 - 3 + 2 = 3
Travel to station 1. Your tank = 3 - 3 + 3 = 3
You cannot travel back to station 2, as it requires 4 unit of gas but you only have 3.
Therefore, you can't travel around the circuit once no matter where you start.
"""

class Solution:

    def can_complete_circuit(self, gas, cost):
        total_gas = 0
        total_cost = 0
        tank = 0
        start_index = 0
        for i in range(len(gas)):
            total_gas += gas[i]
            total_cost += cost[i]
            tank += gas[i] - cost[i]
            if tank < 0:
                start_index = i + 1
                tank = 0
        if total_gas < total_cost:
            return -1
        return start_index


if __name__ == '__main__':
    # Example usage based on LeetCode sample
    solution = Solution()
    
    # Example 1
    gas1 = [1, 2, 3, 4, 5]
    cost1 = [3, 4, 5, 1, 2]
    result1 = solution.can_complete_circuit(gas1, cost1)
    print(f"Example 1: Starting index = {result1}")  # Expected output: 3
    
    # Example 2
    gas2 = [2, 3, 4]
    cost2 = [3, 4, 3]
    result2 = solution.can_complete_circuit(gas2, cost2)
    print(f"Example 2: Starting index = {result2}")  # Expected output: -1
    
    # Additional example
    gas3 = [5, 1, 2, 3, 4]
    cost3 = [4, 4, 1, 5, 1]
    result3 = solution.can_complete_circuit(gas3, cost3)
    print(f"Example 3: Starting index = {result3}")  # Expected output: 4
